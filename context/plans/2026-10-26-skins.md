# Plan: skinnable table UI (Café Tunisien default + Modern Minimal)

**Decision (user):**
- Players can switch skins.
- Café Tunisien is the default and the preferred look.
- Modern Minimal is the second skin.
- Sidi Bou Said (`context/ui/chkobba-design-2-sidi-bou-said.html`) is kept as a future skin.

Prototypes live in `context/ui/`.

**Rule:** skins change visuals only. Layout and interaction are shared, so a UI change is made once.

## Skin contract (`apps/mobile/src/skins/types.ts`)

- `tokens`: colours, fonts, radii, card sizes, hand-fan geometry, badge colours.
- `components`, the slots where the skins genuinely differ in drawing:

| Slot | Café | Minimal |
|---|---|---|
| `Background` | Wood planks | Flat dark |
| `TableSurface` | Baize with brass rim | Dark region |
| `CardFace` | Pips and illustrated busts | Oversized index |
| `CardBack` | Lattice | Outline |
| `Avatar` | Brass medal with glow | Ring |
| `ScoreBoard` | Racham notebook with tallies | Chips |
| `Panel` | Paper | Dark card |
| `Celebration` | Stamp and confetti | Slam |
| `Wordmark` | — | — |

- Later, skins become shop items: `premium` and ownership come from the Nakama wallet. Everything is unlocked for now.

## Shared UX (from all three prototypes)

- **Numbered captures:** capture options are numbered, and the same numbers are stamped on the table cards. One tap on an option plays it. Tapping a highlighted table card plays it when that is unambiguous.
- **Last-played marker:** the last card placed on the table gets a dashed outline and the placer's name tag.
- **Turn indicator:** a glowing or ringed avatar, plus a lit name plate and a "Your turn" pill.
- **Captured-pile and sweep counts** stay visible in the scoreboard.
- **Chkobba celebration overlay.** Bots wait longer after a sweep so it can be seen.
- **Round summary:** shows the Arabic terminology.

## Deliberately not done yet

- **Turn timer:** there's no timer in offline play. The ring shows whose turn it is, not a countdown; the countdown arrives with online play.
- **Illustrated face cards:** Café uses the prototype's simple SVG busts. Finer art comes later.
