Emotes · a fixed set, no typing

Players react with a short list of emoji and Tunisian phrases. Nothing is typed, so there is nothing to moderate. A bubble pops out of the sender's seat for about 2.5 seconds, styled by the table design. Try the live table: send an emote, and the bots answer now and then. Tap an opponent's avatar to mute them. After you send one there is a 3-second cooldown. Switch the table style and language above.

Rules

  • Fixed set only. Six emoji and six phrases at launch. No free text, so no chat moderation or report flow is needed yet.
  • Quick row = last used. The four most recently sent emotes, newest first, saved on the device. It starts as 👍 😂 Yalla! 🤦. It reorders when the cooldown ends, never under your finger.
  • Cooldown. One emote every 3 seconds per player. The server enforces it too (it drops extras), so a modified client can't spam.
  • Mute. Tap a seat → Mute emotes. It's per player and only on your device; their bubbles stop showing. "Mute all" lives in Settings.
  • Bots emote sometimes: "Mabrouk!" when their side sweeps, 🔥 after a big capture, 🤦 when they lose a 7♦. This makes offline games feel alive.
  • Phrases are translated. Each emote is an id like yalla. Every player sees it in their own language (يلّا in Derja, "Yalla!" in English).

How it would be built

  • Protocol (additive): client → server EMOTE {id}; server → clients EMOTE_SHOWN {seat, id}. It's a separate message, not part of the snapshot, so the snapshot fingerprint is unchanged.
  • Server: checks the id is in the allowed list and the sender holds a seat, applies the per-seat 3 s limit, then broadcasts.
  • Client: a GameClient.sendEmote(id) method plus an emotes event stream. LocalGameClient generates bot emotes. One shared EmoteBubble component reads the skin tokens, with no per-skin layout.
  • Accessibility: each bubble is announced ("Karim: Yalla!"). Under reduce-motion it fades instead of popping.

Later

  • Emote packs as cosmetics (shown locked in frame b), unlocked by playing or in the shop. The ownership record would be shared with avatars and frames.
  • Desktop: press E to open the picker, then 1–9 to send.
  • Open question: should partners get a few private "signals" (e.g. "I have the 7♦")? That changes the game, and many Tunisian tables would call it cheating, so it's left out.
